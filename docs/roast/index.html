How the GitHub score works

Six areas, each scored out of 10 from public data, using the same rubric as the roast-my-github agent skill. The overall score is the average.

AreaBased on
ProfileBio, display name, website, and a profile README repo (<user>/<user>, or .github for orgs)
Repo hygieneShare of your own repos with a description, a license and topics
ActivityHow recently you pushed, how many repos are stale, and output vs account age
ImpactStars, forks and followers, log-scaled so you don't need to be famous
FocusHow concentrated your languages are, and originals vs forks
Commit craftShare of recent commit messages that actually say something (not "fix", "wip", "update")

Every roast line points at a real number from the profile. It roasts code and habits, never the person, and always ends on something good.

FAQ

How does Roast My GitHub work?

It reads your public profile and your 100 most recently pushed repos from the GitHub API, right in your browser, then scores six areas out of 10 and writes roast lines that each point at a real number from your profile. No login, no server, no AI guessing.

Is it okay to roast someone else's GitHub?

It only uses public data, but keep it friendly: roast yourself, or friends who are in on the joke.

Why does it say I hit the rate limit?

GitHub allows 60 anonymous API requests per hour per IP address, and a roast uses 3 or 4. Wait for the reset, or install the roast-my-github skill and set GITHUB_TOKEN for unlimited roasts.

How do I improve my GitHub profile score?

Write a profile README, give every repo a one-line description, a license and a few topics, archive repos you no longer touch, pin your best work, and write commit messages that say what changed and why.
