Full skill instructions (SKILL.md)

YouTube Script Writer

Hold attention from second 0 to the end screen.

1. Brief

Topic, target viewer, the one promise of the video (what they'll get by the end), length (Short of 60 seconds or less, or long-form 8–15 minutes), style (talking head, faceless voiceover, tutorial, documentary), the creator's voice and any sources or facts to use. If the user provides research, use only facts from it or well-established knowledge, and mark claims that need verifying with [VERIFY].

2. Structure (long-form)

[0:00–0:30] HOOK
  - Visual/claim that matches the title & thumbnail promise immediately
  - Stakes: why this matters to the viewer
  - Open loop: "and the 3rd one surprised me the most"
  - No "Hey guys, welcome back" before value
[0:30–1:00] SETUP — credibility in one line, roadmap of the video
[BODY] 3–7 segments, each:
  - mini-hook → point → example/story/demo → payoff → transition that opens next loop
  - pattern interrupt every 60–90s (B-roll, graphic, zoom, joke, question)
[Mid-roll] sponsor or CTA bridged naturally from content
[CLIMAX] best point saved for late (pays off the open loop)
[END] quick recap → next-video CTA (point to specific video) — no long outro

3. Output format (a two-column script)

Spoken (A-roll)Visual / B-roll / on-screen text / SFX
"Most people get this wrong..."[Zoom-in] Text: "❌ Common mistake"

Then add: the estimated runtime (about 150 words per minute), a list of the B-roll shots to film or source, and 3 title and thumbnail pairings that match the hook (for youtube-seo-optimizer).

4. Shorts version

45 seconds or less, the hook in the first second, one idea only, a fast payoff, and a loop ending. Write it as a separate script.

Style rules

  • Write for the ear: short sentences, contractions, "you" language, one idea per sentence.
  • Use specific examples and numbers instead of generic advice.
  • Remove filler, and cut any sentence that doesn't move the story forward.
  • Read it in the creator's voice. Ask for an earlier script or transcript to match their style.
  • Sponsored segments must be clearly disclosed.
