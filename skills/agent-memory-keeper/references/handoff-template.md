# HANDOFF.md template

`python3 scripts/handoff.py --write HANDOFF.md` writes this skeleton with the Git state section filled in. Replace every `<fill in …>` and keep the whole file under about 60 lines. Write facts, not a story of the session.

## What goes in each section

| Section | Write | Avoid |
|---|---|---|
| Goal | One line, quoting the user where possible | A restated plan |
| Status | A checklist: done `[x]`, in progress `[ ]` with how far, not started `[ ]` | Paragraphs |
| Next step | One command or `file:line` plus the action, so a cold reader can start in a minute | "Continue the work", "finish the feature" |
| Decisions | The choice and the reason, including choices the user made | Choices nobody would question |
| Tried and failed | What was tried and the concrete reason it failed | Things that worked |
| Open questions | Only what the user must answer; "none" is fine | Questions the next session can answer by reading code |
| Verify | Commands that prove the work so far, the ones you actually ran | Untested commands |
| Git state | Generated by the script. If the state changed after writing, run `handoff.py` again and paste the new block | Hand edits |
| Links | Issue, PR, design doc, thread | Secrets, tokens, signed URLs |

The script also prints commits on the branch, files changed and TODO/FIXME/XXX lines added. Keep them in the Git state block if they help the next session; drop them if the file gets long.

## Lifecycle

- One HANDOFF.md per task at the repo root (or wherever the user prefers). Overwrite it at each handoff with `--write HANDOFF.md --force`, then fill it in again.
- Lessons that outlive the task (a verified command, a gotcha, a preference) go to MEMORY.md at handoff time, not here.
- When the task is done, delete it, or move it to `docs/handoffs/<date>-<topic>.md` if the user wants a record.
- Keep it out of git (`.gitignore`) unless it is a handoff to a teammate through the branch. Committing it moves HEAD by one commit; `--check` recognises that case and does not call it drift.
