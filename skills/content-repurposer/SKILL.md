# Content Repurposer

One idea, 15+ assets, each native to its platform rather than copy-pasted.

## 1. Ingest

Accept a transcript, an article, notes or a file. For YouTube, ask for the transcript, or fetch it with an available tool.
Extract: the **core thesis**, 5–10 standalone **key insights**, quotable lines, stories, stats (with their source) and a timestamp for each moment.

## 2. Produce the pack

| Asset | Spec |
|---|---|
| 🎬 3–5 short clips (Shorts/Reels/TikTok) | Source timestamps `mm:ss–mm:ss`, a new hook line for the first 2 seconds, on-screen text, caption, and why the clip works standalone |
| 🧵 X/Twitter thread | 6–10 posts, with the hook post containing no link and the link in the last post |
| 💼 LinkedIn post | Story-driven, short lines, a lesson, a question CTA and 3 hashtags |
| 🖼️ Instagram carousel | 8–10 slides of text (see `instagram-growth-manager`) |
| ✉️ Newsletter | Subject line ×3, preview text, about 300 words, one CTA |
| 📝 Blog/SEO article | An outline plus an intro targeting one keyword, and an FAQ |
| 💬 Quote graphics | 5 quotes of 20 words or fewer, with a design note |
| 📌 Pinterest / Threads / Facebook | Short native versions (optional) |

## 3. Schedule

Suggest a 2-week drip schedule so the assets don't all go out on the same day, each linking back to the original.

## Rules

- Rewrite natively for each platform's tone, length and format. Never paste the same text everywhere.
- Keep the creator's voice, and never add claims that aren't in the source.
- Put the attribution in clips and links to the original content.
- Output one Markdown file per platform in `repurposed/<slug>/`, or everything inline if the user prefers.
