# Pinterest

Pinterest as a visual search engine for blog and shop traffic: business setup, keyword research, boards, Pin titles, descriptions and alt text, video Pins, fresh-Pin cadence, seasonal planning, Rich Pins and analytics.

## Platform facts

| Item | Limit / note |
|---|---|
| Pin title | 100 characters. Only the start shows in the feed, so put the keyword first |
| Pin description | 500 characters |
| Alt text | 500 characters |
| Image ratio | 2:3 vertical, e.g. 1000×1500 px. Much taller images get cropped in the feed |
| Video Pins | Vertical (2:3, 4:5 or 9:16) work best |
| Idea Pins | Folded into standard Pins in 2023. Any Pin can now be multi-image or video, with or without a link |
| Rich Pins | Product, recipe and article data pulled from schema.org or Open Graph metadata on the user's site |

## How visibility works

- Pinterest behaves more like a search engine than a feed. Keywords in the Pin title, description, board name, alt text and the landing page decide where a Pin shows up. Hashtags matter little now.
- Pins keep getting traffic for months, so the work compounds.
- Pinterest favours fresh Pins: new images, even for the same URL, count as new content. Re-saving the same Pin to many boards does not.
- Saves and outbound clicks are the signals that matter for traffic goals.
- People plan ahead. Seasonal searches (holidays, back to school, summer) start rising weeks to months before the date; 45–90 days is often quoted, but check Pinterest Trends for the real ramp in the user's niche.

## Intake (save to `social/pinterest.md`)

- Website, the main pages or products to drive traffic to, and the niche.
- Business account? Website claimed? Rich Pin metadata in place?
- Brand assets: fonts, colours, logo, photo library.
- Current boards and monthly views or outbound clicks, if known.
- How many Pins a week they can realistically make.

## Deliverables

**Setup**: business account, claimed website (meta tag, HTML file or DNS record), Rich Pin metadata, a profile name with a keyword ("Anna | Easy Vegan Recipes"), a keyword-rich bio, cover image.

**Keyword research**: use Pinterest search autocomplete, the related-search chips and Pinterest Trends. The user pastes them in or a browser tool fetches them. Output a keyword list grouped by topic, with notes on seasonality.

**Board architecture**: 10–20 boards named after searchable keywords ("Small Bathroom Ideas", not "Bathroom Love"), each with a 2–3 sentence description using keywords naturally. Most important boards at the top.

**Pins**
- Design: 2:3 vertical, bold readable text overlay, brand mark, high contrast.
- Title: primary keyword + benefit. Description: natural sentences with 2–4 keywords and a CTA. Alt text describing the image.
- Link to the specific page or product, never just the homepage.
- 3–5 Pin designs per blog post or product, spread over weeks.

**Cadence and seasonal calendar**: consistent scheduling (for example 1–5 fresh Pins a day) beats bursts. A calendar that publishes seasonal content well before the date.

**Analytics review**: impressions, saves, outbound clicks, click-through rate per Pin and board, top Pins, keywords to double down on, next actions.

## Policy and ToS

- Pinterest's spam rules prohibit keyword stuffing, misleading Pins, link cloaking or redirects and repetitive mass saving.
- Affiliate links are allowed when disclosed. Paid partnerships use Pinterest's paid partnership tool.
- Only use images the user owns or is licensed to use.

## Tools and posting

- Native scheduling in Pinterest, or Tailwind, Later, Buffer and similar tools.
- Pinterest API v5 for custom publishing (needs an approved app).
- Draft everything; publish or schedule only through the user's connected tools, after they confirm.

## Review checklist

- [ ] Primary keyword at the start of the title
- [ ] Description reads like a sentence, not a keyword list
- [ ] Alt text present
- [ ] Link goes to the exact page or product
- [ ] Image is 2:3 and text is readable on a phone
- [ ] Seasonal Pins are scheduled ahead of the date
- [ ] Affiliate links disclosed; user approved before publishing
