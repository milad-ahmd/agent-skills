# X (Twitter)

Growing an X account: profile, positioning, daily posts, threads, reply strategy, build-in-public, Spaces and Communities, content banks and analytics.

## Platform facts

X changes features and limits often, especially for paid tiers. Check before relying on a number.

| Item | Limit / note |
|---|---|
| Post | 280 characters on free accounts. Premium allows much longer posts |
| Bio | 160 characters |
| Display name | 50 characters |
| Media | Up to 4 images, or one video / GIF per post. Video length limits depend on the tier |
| Thread | A chain of replies to your own post |
| Pinned post | One per profile |

## How visibility works

- The "For you" feed ranks posts by predicted engagement. Replies and conversations weigh heavily, which is why replying well is the fastest growth lever for small accounts.
- X has said Premium subscribers get prioritised placement in replies and search. Whether that is worth paying for depends on the user's goals.
- Posts with external links are widely reported to get less reach. Common workaround: put the link in a reply or the last post of a thread. Test it on the account.
- Early engagement after posting matters, so post when the user's audience is online and be around to reply.

## Intake (save to `social/x.md`)

- Niche in one sentence ("I help X do Y"), audience and goal (followers, leads, launches, a job).
- Voice, 5 accounts the user admires and why.
- Current followers, posting history, time per day.
- Any real numbers or stories they're happy to share (for build-in-public).

## Deliverables

**Profile**: 3 bio options (who you are, what you post about, proof or personality). Header image showing the topic or offer. Pinned post: best thread or an intro. Optional keyword in the name field ("Milad | Building AI tools").

**Content mix** (a starting point; adjust to what the analytics show):

| Type | Share | Example |
|---|---|---|
| Insight / tip | ~40% | One sharp, specific lesson |
| Story / build-in-public | ~25% | Progress, real numbers, real failures |
| Opinion / contrarian | ~15% | A well-argued take in the niche |
| Engagement | ~10% | Questions, "what would you add?" |
| Promo | ≤10% | Product or newsletter link |
| Thread | 1–2 a week | 6–12 posts of deep value |

**Content bank**: 30 post ideas with drafts. Recycle the best posts every 6–8 weeks with a new angle.

**Writing rules**
- The first line does the work: specific, concrete, no preamble.
- Short sentences, line breaks, one idea per post. Numbers only if the user provided them.
- Threads: hook post without a link → numbered value posts → summary → CTA (follow, repost the first post, link) in the last post.
- Images, screenshots or short clips where they add something.

**Reply strategy**: 10–30 thoughtful replies a day to larger accounts in the niche: add value, a counterpoint or a personal experience, never "great post!". Draft example replies when the user shares target posts.

**Spaces / Communities**: only if the user can show up regularly. Outline topic, guests, run of show and a recap post.

**Analytics review**: impressions, engagement rate, profile visits, follows per post, link clicks. Top 5 posts and the pattern behind them (topic, format, hook, time), then next week's plan.

## Policy and ToS

- X's platform manipulation and spam policy bans follow-for-follow schemes, engagement farming, coordinated inauthentic activity, mass or duplicate posting and bulk unsolicited DMs or mentions.
- Automated accounts must follow X's automation rules and be labelled as automated.
- Paid partnerships and affiliate links must be disclosed. Mark opinions as opinions and don't spread misinformation.

## Tools and posting

- X has a native scheduler (web). Typefully, Buffer, Hypefury and similar tools post through the API.
- The X API is paid and tiered, and its free tier is very limited. Limits and prices change, so check before building any automation.
- Draft everything; post or schedule only through the user's connected tools, after they confirm.

## Review checklist

- [ ] First line is specific and stands alone
- [ ] Fits the length limit for the user's tier
- [ ] No link in the hook post of a thread
- [ ] Facts and numbers come from the user
- [ ] Sponsored or affiliate content is disclosed
- [ ] User has approved before anything is posted
